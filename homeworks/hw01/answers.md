Что означает одна строка каждого файла?
- wells.csv: координаты и результаты измерений для одной скважины.
- layers.xlsx: физические характеристики одного геологического слоя.
- pumping_test.txt: замеры давления в определенный момент времени (в часах).

1)Чем DataFrame отличается от массива NumPy?
DataFrame в Pandas — это двумерная таблица с именованными строками и столбцами, способная хранить данные разных типов. Массив NumPy (ndarray) — это структура данных, которая может быть многомерной и содержит элементы строго одного типа, что оптимизировано для математических вычислений.

2)Что означают две величины в shape массива (13, 2)?
13 — это количество строк (размер по первому измерению), а 2 — количество столбцов (размер по второму измерению).

3)Почему pressure * 1_000_000 не требует цикла for?
Библиотека Pandas использует векторизованные операции: действие применяется ко всем элементам столбца одновременно.

4)Что выбирает срез array[::2]?
Он выбирает каждый второй элемент, начиная с самого первого (индекс 0).

5)Что содержится в логической маске?
Массив булевых значений: True (если условие для элемента выполнено) и False (если не выполнено).

6)Зачем после сохранения загружать массив обратно?
Для проверки целостности: чтобы убедиться, что данные не повредились при сохранении в файл и корректно читаются обратно в память.

7)Какие файлы являются исходными, а какие создаются программой?
Исходные: wells.csv, layers.xlsx, pumping_test.txt.
Создаются: wells_clean.csv, table_summary.xlsx, pressure_matrix.npy, pressure_cube.npz, results.txt.
